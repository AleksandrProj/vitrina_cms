# CMS для партнерских проектов

## Инструкция по установке

### Локальная установка
1. Делаем файл .env из .env.example (cp .env.example .env)
2. Меняем данные в .env файле на свои
3. Запускаем команду "docker compose -f docker/docker-compose.yaml up -d --build"

### Установка в Production
1. Клонировать проект на сервер 
2. Если есть дамп БД, то можно его накатить 
3. Необходимо поменять файлы favicon в папке static/images/favicon/*
4. Поменять весь контент через админку сайта
5. Поменять в админке сайта домен сайта (настройки -> сайты)
6. Добавить в .env свои данные для сайта 

## Что надо сделать когда сайт загрузим на сервер
1. Добавить в https://webmaster.yandex.ru
2. Добавить в https://search.google.com/search-console
3. Добавить счетчики аналитики от Yandex и Google
4. Собрать семантическое ядро
5. Наполнить сайт основным контентом (шапка и подвал сайта, информация сайта и др.)
6. Наполнить сайт вакансиями
7. Наполнить сайт статьями
8. Замерить сайт через https://pagespeed.web.dev
9. Проверяем валидность HTML через https://validator.w3.org/
10. Проверям валидность CSS через https://jigsaw.w3.org/css-validator/ 

## Как добавляем контент на сайт
1. Выбираем ключевые слова из семантического ядра по которым будем писать статью или вакансию
2. Пишем статью с помощью ChatGPT
3. Подбираем картинки для статьи (можно использовать Midjorney и т.п.) и оптимизируем изображения
4. Проверяем написаный контент на уникальность через https://text.ru/, https://advego.com/antiplagiat/ и т.п. сервисы
5. Проверяем текст на "тошноту" ключевых слов через https://pr-cy.ru/tools/content-analysis/, https://advego.com/text/seo/
5. Заливаем контент на сайт

## Замечания по Операционным системам
### Linux/Ubuntu
- При работе на Linux/Ubuntu необходимо на папки которые монтируются через volume ставить права 777
- makemigrations запускаем основном терминале, а migrate в терминале самого docker контейнера
